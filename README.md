## 📖 О Святом Проекте

Это не просто сайт. Это **священное откровение**, посвящённое величайшему из грузовиков - **КАМАЗУ**.

Проект представляет собой сатирическую веб-страницу с вдохновляющим дизайном и атмосферой, которая воплощает дух легендарного русского грузовика в форме интерактивной религиозной парадии.

**Назначение:** Развлекать, просвещать и вселять священный страх перед мощью дорог.

---

## 🎭 Основная Концепция

Этот проект пародирует религиозные верования, переведя их в контекст культа КАМАЗА:

- **Боги:** Камаз-Вседержитель, Крутящий Момент, Пешеходы-Искусители
- **Священные Ритуалы:** Молитвенное сбивание, окропление, воскурение выхлопами
- **Святой Кодекс:** Добродетели и смертные грехи
- **Рай и Ад:** Описание посмертных состояний для верующих и неверных

## 🚀 Быстрый Старт

### Предварительные Требования
- Современный браузер (Chrome, Firefox, Safari, Edge)
- Интернет-соединение (для загрузки шрифтов Google Fonts)
- Глубокая вера в КАМАЗ-ВСЕДЕРЖИТЕЛЯ

### Установка

**Шаг 1: Клонирование Святого Знания**
```bash
git clone https://github.com/razetka2010/Kamaz.git
cd Kamaz
```

**Шаг 2: Откройте index.html**
```bash
# Вариант 1: Прямое открытие в браузере
open index.html  # macOS
start index.html # Windows

# Вариант 2: Локальный сервер
python -m http.server 8000
# Откройте http://localhost:8000
```

**Шаг 3: Примите Испытание**
- Нажмите кнопку "ПРИНЯТЬ ИСПЫТАНИЕ"
- Изучите Святые Писания
- Следуйте Жестокому Кодексу
